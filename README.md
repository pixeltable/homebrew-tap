# Pixeltable Tap

## How do I install these formulae?

`brew install pixeltable/tap/<formula>`

Or `brew tap pixeltable/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "pixeltable/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
